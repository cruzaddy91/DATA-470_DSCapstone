# Security

## Reporting a vulnerability

If you believe you have found a security issue in this repository, please email the maintainer via the contact address on [addycportfolio.netlify.app](https://addycportfolio.netlify.app) rather than opening a public issue.

Do not commit `.env` files, API keys, or SAP raw extracts. See [data/README.md](data/README.md) for how to obtain dataset files locally.
