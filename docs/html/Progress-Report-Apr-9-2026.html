Comparing the three validations

Split What it tests Logistic regression (headline)
Temporal (global) Train on all orders before cutoff; test on later calendar period. Closest to “past → future” on full history. F1 0.28, ROC-AUC 0.85, PR-AUC 0.19 — sparse test positives (58).
Grouped Hold out whole sales documents; train/test can overlap in time. Stress-tests document-level correlation. F1 0.41, ROC-AUC 0.84, PR-AUC 0.31 — more positives in test (197).
Recent 24-week Only the last 24 weeks of data; then a second date cutoff inside that window. Matches “train on recent season only.” ROC-AUC 0.89 for logistic, but threshold tuning on tiny train positives (24) yields no predicted positives on test → precision/recall/F1 read as 0. Too few events for stable threshold metrics.
v3 stratified 80/20 Recent order window + demand/WOC features; random stratified train/test (80/20). Stress-tests richer features and class balance mechanics, not strict time-forward generalization. LightGBM F1 0.55, PR-AUC 0.70 on this holdout — useful for comparison; keep v2 temporal as the conservative production story.
Takeaway: The v2 24-week temporal slice is for recency stress-testing and ranking under a narrow regime. The v3 split is a different question (richer inputs, random stratified evaluation). Production narrative stays anchored on v2 temporal unless stakeholders explicitly accept the v3 assumptions.

Interpretation

Completion line: The capstone delivers a reproducible, leakage-aware binary risk model at order-line grain, honest temporal evaluation, secondary grouped metrics, and demand/excess tables for operational narrative.
Caveats for readers: High accuracy reflects class imbalance; prioritize PR-AUC, F1, and precision at the chosen threshold. Global temporal test positives are few; the 24-week slice is even sparser on the test tail — interpret its F1/precision literally as “thresholded predictions hit zero positives,” not as proof the model has no signal (see ROC-AUC). Re-running on refreshed data may shift numbers slightly.
